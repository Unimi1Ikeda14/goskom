# 🛠️ Инструкция по установке и локальному запуску платформы GosKom

Данное руководство содержит полное описание процесса развертывания веб-приложения **GosKom** на локальном компьютере для целей разработки, тестирования или демонстрации проекта.

---

## 1. Системные требования

Перед началом установки убедитесь, что в вашей системе настроено следующее программное обеспечение:
* **Java Development Kit (JDK):** Версия **17** или выше (рекомендуется OpenJDK 17 / Corretto 17).
* **Apache Maven:** Версия **3.8+** (для сборки проекта и управления зависимостями).
* **Браузер:** Любой современный веб-браузер (Google Chrome, Mozilla Firefox, Microsoft Edge).
* **Git:** Для клонирования репозитория (необязательно, если проект скачан архивом).

---

## 2. Подготовка базы данных (Важно для проверки)

Платформа использует встроенную легковесную реляционную СУБД **SQLite**. 
* **Никаких внешних серверов:** Вам **не требуется** скачивать, устанавливать или настраивать СУБД вроде PostgreSQL, MySQL или разворачивать Docker-контейнеры.
* **Автоматическое создание:** Файл базы данных (`goskom.db`) инициализируется самостоятельно в корневой папке проекта при самом первом запуске приложения.
* **Генерация схемы:** Все таблицы, индексы и связи между сущностями разворачиваются автоматически силами Hibernate/JPA (`ddl-auto: update`). Никакие SQL-скрипты вручную накатывать не нужно.

---

## 3. Пошаговое развертывание и запуск

### Шаг 1: Получение исходного кода
Скачайте архив с проектом и распакуйте его либо склонируйте репозиторий через терминал:
```bash
git clone [https://github.com/ВАШ_НИКНЕЙМ/goskom.git](https://github.com/ВАШ_НИКНЕЙМ/goskom.git)
cd goskom
```
### Шаг 2: Сборка и запуск приложения

Вы можете запустить проект быстрым способом через Maven. Выполните команду в директории проекта (там, где лежит файл `pom.xml`):

```bash
mvn spring-boot:run
```
Шаг 3: Проверка работоспособности
После того как в консоли отобразится финальный лог запуска (Started GoskomApplication in ... seconds), приложение полностью готово к работе.

Откройте браузер и перейдите по адресу:

```bash 
http://localhost:8080
```
Вы должны увидеть приветственный экран (главную страницу) платформы «ГосКом».
